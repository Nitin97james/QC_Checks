## 🛠️ Featured Project

### [Warehouse QC Management System](https://nitin97james.github.io/QC_Checks/)

> A real-time web application built to replace manual WhatsApp-based quality check logging across a 4-site warehouse operation.

**What it does:**
- Live data sync across 20+ users via Firebase Realtime Database
- Role-based access control with admin approval workflow
- Mandatory photo evidence uploads with automatic compression (Cloudinary)
- Automated PDF compliance report generation — app data overlaid directly onto official company documents
- 30-day audit history with full drill-down by site, time and staff member
- Check assignment system with accountability tracking

**Built with:** JavaScript · Firebase · Cloudinary · jsPDF · GitHub Pages

**The challenge:** Built independently with no formal software development background — from identifying the problem to deploying a production-ready solution.
